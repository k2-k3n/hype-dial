# Hype Engine

合成电子鼓、低音和旋律。不同曲风有各自的节奏和音色，ENERGY 决定加入多少伴奏层。

## 使用方法

1. 先在 Resona Box 上安装本音频包。
2. 安装并打开 Hype Dial 0.4.9。
3. 在 App 界面使用上方和下方编码器控制音色与功能。

## 配套关系

- 音频包：`org.resona.demo.hype-engine`，版本 0.3.12
- App：`org.resona.demo.hype-dial`，版本 0.4.9

完整界面及双编码器的旋转、短按、长按说明见 Hype Dial 的社区项目页面。

## 0.3.12

底鼓起音加入 1 ms 渐入，并下调底鼓输出以留出余量。STUTTER、ROLL 和 SCRATCH 会等到所需的节拍片段录满再启动。
